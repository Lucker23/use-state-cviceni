# Examples

Pattern files referenced by `INITIAL.md`. Fill these in before running `/generate-prp`:

- `opendota-fetch.ts` — OpenDota API calls with rate-limit handling
- `claude-stream.ts` — streaming Claude responses via Vercel AI SDK
- `supabase-rls.sql` — row-level security policies for user data
- `coach-prompt.md` — system prompt with Dota lingo rules
- `match-context-builder.ts` — compress a parsed match into ~2k tokens
